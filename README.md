# 直播分档榜

一个用于直播展示的 Windows / macOS 跨平台分档榜桌面应用。

## 功能

- 100% 宽高、随窗口响应式缩放的榜单主界面
- 候选项在候选列表与各分档之间实时拖放
- 每个分档内的项目自动换行，行高和整张表会随内容向下扩展
- 主榜单和设置预览中的表格使用直角边框，外层展示卡片保留圆角
- 单个分档增高时会先压缩其他分档的空白高度，全部达到最低高度后才让页面滚动
- 候选列表可选“横向滚动”或“自动换行并增高”两种布局
- 自定义分档名称、颜色、顺序、数量，并提供“从夯到拉”和“S 到 D”模板
- 支持纯文本、纯图片、图片 + 文本三种候选项
- 纯文本支持回车快速添加；输入英文逗号时可选择整条添加或拆分为多个候选项
- 纯图片与图片 + 文本支持一次选择多张图片，并在添加前显示正方形预览
- 图片 + 文本模式自动使用图片文件名（不含扩展名）作为标签
- 非方形图片统一居中裁切为正方形显示
- 添加按钮旁可直接批量导入 `.xlsx` 和 `.zip`
- 支持候选项一键按标签去重，以及点击候选项后编辑标签和图片
- 基本设置可自定义或隐藏 Logo、大标题和小标题；显隐切换立即生效，大标题同时作为应用窗口标题
- “显示尺寸”卡片内提供一行真实榜单预览，可实时查看分档字体、候选标签字体和图片尺寸的调整效果，并逐项恢复默认值
- 自动保存全部数据到本机 IndexedDB
- 红色重置按钮带二次确认；“导出图片”可将榜单区域保存为 PNG
- 桌面窗口最小宽度为 560px，适合更紧凑的直播布局
- 关闭最后一个窗口时直接退出应用，在 macOS 下不会继续驻留 Dock

## Excel / ZIP 导入格式

### Excel

在“候选项管理”的添加区域点击“批量导入”并选择 `.xlsx` 文件。任一前 20 行中必须存在表头为 `选项名` 的列。该列下方的非空单元格会导入为纯文本候选项。

### ZIP

ZIP 内必须包含：

- 一个 `.xlsx` 文件，表格格式同上；
- 一个 `images` 文件夹。

图片文件的文件名（不含扩展名）与“选项名”一致时，会导入为“图片 + 文本”候选项；没有匹配图片的项目会回退为纯文本。支持 PNG、JPG/JPEG、GIF、WebP、BMP、AVIF、SVG。

示例：

```text
候选项.zip
├── candidates.xlsx
└── images
    ├── 玩具.png
    └── 水果.webp
```

## 本地运行

```bash
npm install
npm run dev
```

## 构建与打包

```bash
npm run build
npm run dist:mac
npm run dist:win
```

安装包输出到 `release/`。
