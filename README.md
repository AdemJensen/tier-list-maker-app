# 直播分档榜

一个用于直播展示的 Windows / macOS 跨平台分档榜桌面应用。

## 功能

- 100% 宽高、随窗口响应式缩放的榜单主界面
- 候选项在候选列表与各分档之间实时拖放
- 每个分档内的项目自动换行，行高和整张表会随内容向下扩展
- 单个分档增高时会先压缩其他分档的空白高度，全部达到最低高度后才让页面滚动
- 候选列表可选“横向滚动”或“自动换行并增高”两种布局
- 自定义分档名称、颜色、顺序、数量，并提供“从夯到拉”和“S 到 D”模板
- 支持纯文本、纯图片、图片 + 文本三种候选项
- 非方形图片统一居中裁切为正方形显示
- 支持 `.xlsx` 和 `.zip` 批量导入
- 自动保存全部数据到本机 IndexedDB
- 一键重置排名，以及将榜单区域保存为 PNG

## Excel / ZIP 导入格式

### Excel

上传 `.xlsx` 文件，任一前 20 行中必须存在表头为 `选项名` 的列。该列下方的非空单元格会导入为纯文本候选项。

### ZIP

ZIP 内必须包含：

- 一个 `.xlsx` 文件，表格格式同上；
- 一个 `images` 文件夹。

图片文件的文件名（不含扩展名）与“选项名”一致时，会导入为“图片 + 文本”候选项；没有匹配图片的项目会回退为纯文本。支持 PNG、JPG/JPEG、GIF、WebP、BMP、AVIF、SVG。

示例：

```text
候选项.zip
├── candidates.xlsx
└── images
    ├── 玩具.png
    └── 水果.webp
```

## 本地运行

```bash
npm install
npm run dev
```

## 构建与打包

```bash
npm run build
npm run dist:mac
npm run dist:win
```

安装包输出到 `release/`。
